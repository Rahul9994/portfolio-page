01 About me

Engineering where AI, security and hardware meet.

I'm Rahul Penugonda, a B.Tech Artificial Intelligence student at Amrita Vishwa Vidyapeetham (2024–2028, CGPA 8.74), based in Hyderabad, India. I like systems that cross boundaries — software that talks to hardware, models that run on robots, and products that are secure by design.

My work spans AI/ML and computer vision, cybersecurity and cloud security, networking and Linux, embedded systems and full-stack development. I've simulated an autonomous drone running onboard CNN inference, built an ESP32-CAM face-recognition security system, repurposed a desktop into a NAS server, and shipped LLM-powered web apps to production.

I work documentation-first: understand the problem, debug to the root cause, test iteratively, and leave behind something others can reproduce.
